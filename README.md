# Ryware Homebrew tap

```sh
brew install ryware/tap/headroom
```

| App | Install | Source |
| --- | --- | --- |
| Headroom: free disk space analyzer for macOS | `brew install ryware/tap/headroom` | [Ryware/Headroom](https://github.com/Ryware/Headroom) |

`Casks/headroom.rb` is updated automatically when a new Headroom release is published.
